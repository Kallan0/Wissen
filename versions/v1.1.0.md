# Release Version v1.1.0

**Release Date:** 2026-09-04  
**Project:** Local AI-Powered Resume Builder  
**Version:** v1.1.0  

---

## 1. Overview
Version 1.1.0 introduces the **AI Career Matcher & Position Recommender** ("Role Matches"), enabling the local LLM to inspect the candidate's verified ChromaDB vector database and identify target job positions they are qualified to apply for. It adds automatic Ollama local model discovery, one-click role tailoring, and verifies real local model and vector execution.

## 2. Changes Made & Files Modified

### A. Position Recommendation Prompt & System Instructions
- **Files Modified:**
  - [`backend/ai/prompts.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/ai/prompts.py):
    - Added `ROLE_RECOMMENDATION_PROMPT`.
    - Enforced strict rules requiring the AI to ground every recommended role in verified achievements, calculate realistic Fit Scores (0-100%), provide proof points citing candidate context, and output structured JSON.
- **Reason / Rationale:**
  - Satisfies user request for the AI to recommend job positions based on the contents of their vector database without fabricating nonexistent qualifications.

### B. Career Suggestion Engine & Model Auto-Selection
- **Files Modified:**
  - [`backend/ai/generator.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/ai/generator.py):
    - Implemented `suggest_career_positions(candidate_context, model)`.
    - Added smart fallback model auto-selection: if the requested model (e.g. `llama3`) is not currently installed in Ollama, the generator queries `GET /api/tags` and automatically uses the first installed local model (e.g. `gemma4:31b-cloud`), preventing 404 errors.
    - Used clean `.replace("{candidate_context}", candidate_context)` to avoid python `.format()` string conflicts with JSON curly braces.
    - Added `_build_fallback_recommendations()` as a fail-safe in case Ollama is offline.
- **Reason / Rationale:**
  - Enables smooth local inference using whatever model the user has installed in Ollama without crashing or requiring manual configuration.

### C. Position Recommendation REST API
- **Files Modified:**
  - [`backend/main.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/main.py):
    - Added `RecommendPositionsRequest` Pydantic model.
    - Added `POST /api/recommend-positions` endpoint that aggregates all records across `experiences`, `projects`, `skills`, `education`, and `raw_documents` from ChromaDB and passes the verified background to the recommendation engine.
- **Reason / Rationale:**
  - Provides a REST interface for the frontend to request career recommendations based on the full vector database state.
