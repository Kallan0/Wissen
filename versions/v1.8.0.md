# Release v1.8.0 — 2026-09-21

## Overview

Completed the grounded dataset-generation run after making candidate identity deterministic. The local Llama 3 model generated 150 role-balanced examples, which were validated and split into 120 training records and 30 untouched holdout records.

## Detailed changes

### `backend/finetuning/dataset_generator.py`

- Added the exact verified candidate name dynamically to the generation prompt.
- Removed deterministic identity and resume metadata from the model's responsibilities.
- Python now injects the verified name, contact data, employment metadata, project metadata, skills, and education before final validation.
- Limited the model to summaries, experience bullets, project bullets, and match notes.
- Deduplicated ChromaDB experience chunks and project chunks before prompt construction.
- Reduced each prompt to the three most role-relevant projects and bounded generated prose.
- Added one-to-four local generation workers while preserving deterministic output ordering.
- Continued using local `llama3:latest`; the available cloud-hosted model was not used for private profile data.

### `backend/tests/test_dataset_pipeline.py`

- Added regression coverage for deterministic name replacement.
- Added experience/project chunk-deduplication coverage.
- Added coverage proving that Python—not Ollama—owns identity, employment, and project metadata.

### Generated private artifacts

- `backend/data/finetuning/generated_dataset.jsonl`: 150 validated examples.
- `backend/data/finetuning/training_data.jsonl`: 120 examples.
- `backend/data/finetuning/holdout_eval.jsonl`: 30 examples.
- These private/generated files remain excluded by `.gitignore`.

## Dataset verification

- 150 unique structurally valid combined examples.
- 120 training examples and 30 holdout examples.
- Zero exact overlap between training and holdout files.
- One consistent verified candidate name across all outputs.
- 50 Python Backend Developer examples.
- 50 React / Next.js Frontend Developer examples.
- 50 Figma UI/UX Designer examples.
- Nine fine-tuning/dataset regression tests passed.

## Rationale

Probabilistic models should not control deterministic identity or source-of-truth profile fields. Injecting these values in Python permanently prevents harmless name abbreviations—and more serious metadata drift—from poisoning supervised fine-tuning data.
