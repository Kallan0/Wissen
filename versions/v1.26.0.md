# v1.26.0 - Single Joji Master Resume Layout

Date: 2026-10-28

## Summary

Made the supplied `Joji A G_Master.pdf` the sole resume visual specification and removed all alternate template behavior.

## Layout

- Single A4 black-and-white serif design.
- Centered candidate name, muted professional title, and compact icon contact row.
- Centered section headings between horizontal rules.
- Inline company, role, location, and right-aligned dates.
- Bold project titles, right-aligned years, italic technology rows, and concise bullets.
- Two-column categorized skills ledger.
- Compact education rows with right-aligned dates and results.
- Local system fonts only; no external font downloads or decorative template assets.

## Removed

- Modern, Minimal, and Vintage template constants and lookup map.
- Template field from tailoring, HTML preview, and PDF export API contracts.
- Template arguments from frontend API helpers.
- Template selector from Job Tailor.
- Template switcher and template state from Resume Preview.
- Legacy multi-template tests.

## Verification

- Full backend suite: 91 tests passed with one third-party deprecation warning.
- Frontend production build passed.
- Generated preview is one A4 page and was visually compared with the supplied source PDF at 2x rendering resolution.
