# v1.29.0 - Logical chunking and expanded retrieval

## Logical units

- Resume and Markdown headings now define chunk boundaries.
- Flattened PDF text has known resume headings restored before chunking.
- Structured work, project, skill, and education records retain their existing record-aware ingestion paths.
- Unstructured prose continues to use semantic sentence changes as a fallback; character-count windows are not used.

## Query expansion

- Before ChromaDB retrieval, the selected Ollama or Groq model expands the JD into at most 20 related concepts.
- Expansion includes role synonyms, frameworks, tools, adjacent technologies, and transferable competencies.
- A deterministic domain map supplies safe expansions if the selected LLM is unavailable.
- Expanded concepts are search terms only and never become candidate claims.

## Fuzzy hybrid retrieval

- Expanded concepts are appended to all experience, project, skill, education, and source-document searches.
- Retrieval defaults to six matches per category and keeps a configurable permissive minimum score (`HYBRID_MIN_SCORE=0.0`).
- HNSW ANN dense similarity remains weighted at 70%, with normalized BM25 at 30%.
- The UI shows both literal JD keywords and LLM-expanded concepts for auditability.

## Generation

- The prompt may integrate peripheral abilities only when they are both relevant and present in retrieved verified evidence.
- Existing entity, metric, identity, and hallucination guards remain mandatory.
