# Release Version v1.4.0

**Release Date:** 2026-09-04  
**Project:** Local AI-Powered Resume Builder  
**Version:** v1.4.0  

---

## 1. Overview
Version 1.4.0 integrates the **Wissen Tactile Editorial Papercraft Design System** from Google Stitch project `projects/15408599458364454127` ("Wissen — Tactile Typewriter Resume Press"). The entire application UI and PDF generation pipeline have been transformed into a tactile, editorial typewriter press aesthetic with archival paper textures, manila dossier folders, typewriter monospace accents, postal cancellation stamps, and mechanical press buttons, while retaining 100% of the underlying functional features (local ChromaDB RAG, Ollama LLM inference, Headless PDF generation, Career Matcher, and Multi-Source Connectors Hub).
