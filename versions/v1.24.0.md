# v1.24.0 - Semantic Chunking and Hybrid ANN Retrieval

Date: 2026-10-28

## Summary

Upgraded unstructured ingestion and retrieval while retaining deterministic redundancy safeguards and record-aware chunks for structured profile data.

## Semantic ingestion

- Split text and extracted PDF content into sentence and resume-bullet units.
- Embed those units locally with Chroma's default MiniLM embedding function.
- Detect topic changes from adjacent-sentence cosine similarity and close chunks at the configured low-similarity percentile.
- Enforce configurable 60-word minimum and 220-word maximum chunk targets.
- Fall back to non-overlapping fixed word chunks if the semantic embedder is unavailable.
- Replace chunks from the same text/PDF source only after new semantic chunks are successfully processed, preventing old and new chunk strategies from coexisting.
- Preserve structured experience and project chunking because their record and bullet boundaries are already meaningful.

## Hybrid retrieval

- Use Chroma's cosine HNSW index for approximate dense nearest-neighbour candidates.
- Calculate local BM25 relevance over each requested collection.
- Fuse normalized dense and lexical scores using configurable 70/30 weights.
- Return the fused score, dense score, BM25 score, and `hybrid_hnsw_ann_bm25` strategy label for auditability.

## Configuration

- `SEMANTIC_CHUNK_MIN_WORDS=60`
- `SEMANTIC_CHUNK_MAX_WORDS=220`
- `SEMANTIC_CHUNK_BREAK_PERCENTILE=25`
- `HYBRID_DENSE_WEIGHT=0.70`
- `HYBRID_BM25_WEIGHT=0.30`
