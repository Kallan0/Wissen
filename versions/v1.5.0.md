# Release Version v1.5.0

**Release Date:** 2026-09-04

**Version:** v1.5.0

## 1. Overview
Version 1.5.0 restructures the application header and navigation layout to faithfully match the Google Stitch layout (`projects/15408599458364454127`):
1. **Top Header**: Strictly simplified to display only the official Stitch MCP logo and the brand name **"Wissen"** on the left, with a **"Login"** mechanical button on the right.
2. **Right Navigation Panel**: The main application navigation has been moved into the right-hand panel (`w-72 fixed right-0 top-0 bottom-0`), featuring the Artisan Desk profile, vertical navigation push buttons (`[01]` through `[05]`), a `[Draft Entry]` lever button, and ChromaDB/Ollama telemetry.
3. **Local Assets**: The Stitch typewriter key logo and artisan avatar have been persisted locally in `frontend/public/` (`wissen-logo.png`, `artisan-avatar.png`).
