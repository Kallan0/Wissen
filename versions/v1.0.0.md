# Release Version v1.0.0

**Release Date:** 2026-09-04  
**Project:** Local AI-Powered Resume Builder  
**Version:** v1.0.0

---

## 1. Overview

Initial release of the privacy-first, retrieval-augmented generation (RAG) Local AI Resume Builder. The platform enables users to store career history, skills, and projects in a local vector database (ChromaDB) and automatically generate customized, ATS-friendly resumes tailored to any Job Description (JD) using local LLMs (via Ollama) and Playwright headless PDF export.
