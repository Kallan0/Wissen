# Release Version v1.3.0

**Release Date:** 2026-09-04  
**Project:** Local AI-Powered Resume Builder  
**Version:** v1.3.0  

---

## 1. Overview
Version 1.3.0 implements the **Multi-Source Data Connectors Hub** specified in the architecture document. It allows users to automatically ingest and index real career data, creative projects, code repositories, and design case studies from **GitHub**, **Canva / UI-UX design tools**, and **local game engine workspaces (Unity, Blender, and code directories)** directly into the local ChromaDB vector database.

---

## 2. Changes Made & Files Created / Modified

### A. Connector Core Engine (`backend/connectors/`)
- **Files Created:**
  - [`backend/connectors/github_connector.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/connectors/github_connector.py):
    - Fetches public repositories using GitHub API (with optional personal access token support).
    - Extracts repository metrics (stars, forks), programming languages, topics, and automatically fetches and decodes repository `README.md` files for deep project context.
    - Automatically maps detected languages to ChromaDB skills and projects collections.
  - [`backend/connectors/canva_connector.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/connectors/canva_connector.py):
    - Ingests design projects, case studies, and creative portfolios (Canva, Figma, Adobe XD).
    - Extracts design deliverables, prototype URLs, creative tools, and quantifiable user impact metrics, indexing them into projects and skills.
  - [`backend/connectors/creative_fs_connector.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/connectors/creative_fs_connector.py):
    - Local filesystem scanner capable of parsing local project directories.
    - Detects Unity project signatures (`Assets/`, `ProjectSettings/`, `.cs` scripts, `.meta` files).
    - Detects Blender 3D scene files (`.blend`), render assets, and textures.
    - Reads project summaries (`project_summary.txt`, `README.md`) and inventories C#, Python, and Shader component files.
  - [`backend/connectors/__init__.py`](file:///c:/Users/Joji/2026%20Exp/Resume_builder/backend/connectors/__init__.py):
    - Exports all connector singletons.
- **Reason / Rationale:**
  - Implements the modular data ingestion connectors described in the project specification to automatically build the RAG knowledge base from real developer workflows without manual copy-pasting.

### B. Connector REST Endpoints (`backend/main.py`)
- **Files Modified:**
  - Added request schemas: `GitHubSyncRequest`, `CanvaProjectRequest`, and `FilesystemScanRequest`.
  - Added REST endpoints:
    - `POST /api/connectors/github/sync`: Triggers GitHub repository sync and returns synced repo cards and extracted skills.
    - `POST /api/connectors/canva/sync`: Ingests design case studies and returns indexing status.
    - `POST /api/connectors/filesystem/scan`: Scans local folders and returns detected project types and asset highlights.
- **Reason / Rationale:**
  - Exposes clean, typed endpoints for the web frontend to communicate with local ingestion connectors.
