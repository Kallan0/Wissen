# Release v1.16.0 — 2026-09-24

## Overview

Fixed the Colab training failure:

```text
NotImplementedError: _amp_foreach_non_finite_check_and_unscale_cuda not implemented for BFloat16
```

Dataset validation, tokenization, truncation, and LoRA injection had completed. The failure occurred at the first optimizer step because the FP16 AMP gradient scaler received BF16 trainable gradients.

## Changes

### Colab notebook

- Detects `torch.cuda.is_bf16_supported()` and selects BF16 only on compatible GPUs; a T4 uses FP16.
- Uses the selected dtype consistently for bitsandbytes compute and model loading.
- Sets `SFTConfig.fp16` and `SFTConfig.bf16` as mutually exclusive GPU-derived flags.
- After `SFTTrainer` injects LoRA, promotes every trainable adapter parameter to FP32.
- Fails before training if any trainable parameter remains outside FP32.
- Prints the trainable parameter count and dtype before checkpoint discovery and training.

The frozen 4-bit base model remains quantized; only the small trainable adapter is promoted, so the memory impact is limited.

### Local trainer and tests

- Added the same adapter-dtype safety guard to `finetune_llama3.py`.
- Added `test_colab_notebook.py` to compile all Python notebook cells and verify the approved dataset hash, holdout refusal, dynamic precision flags, and FP32 adapter promotion.

## Recovery instructions

Upload the updated notebook to a fresh Colab runtime and run it from the first cell. The prior run had no checkpoint (`Resume checkpoint: none`), so no training progress is lost.
