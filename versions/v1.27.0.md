# v1.27.0 - JSON Resume and reviewed Next.js PDF export

## Architecture

- FastAPI now ends at a structured JSON Resume response and no longer renders, stores, or serves generated PDFs.
- A deterministic adapter maps grounded drafts to official `basics`, `work`, `projects`, `skills`, and `education` fields.
- Wissen Press metadata is isolated under `custom.wissenPress`, as recommended for non-standard JSON Resume data.
- The Next.js `/api/export-pdf` route validates the user-edited document with `@jsonresume/schema` and renders it with `@react-pdf/renderer`.

## Human review

- Generated identity, summary, work entries, project content, skills, education, and highlights are editable before export.
- PDF export is disabled until the user explicitly confirms that the final draft was reviewed.
- Users can download the portable `resume.json` alongside the final PDF.

## Removed backend surface

- Removed Playwright and Jinja2 runtime dependencies.
- Removed the backend PDF generator, backend template, HTML preview route, PDF export route, and PDF download route.
- Removed backend PDF storage configuration and replaced its tests with contract checks proving FastAPI no longer owns PDF generation.

## Verification

- Backend: 86 tests passed.
- Frontend: Next.js production build passed.
- Next.js PDF route: returned HTTP 200 for a schema-valid resume.
- Visual QA: one-page A4 render inspected at 2x with no clipping, overlap, or unreadable text.
