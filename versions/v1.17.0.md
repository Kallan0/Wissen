# v1.17.0 - Backend-Owned Resume Presentation Boundary

Date: 2026-09-24

## Summary

Removed duplicate resume template engines and candidate-data normalization from the frontend. The backend now owns HTML/PDF rendering and strict profile submission normalization, while the frontend is limited to interaction, editing, feedback, and download behavior.

## Changes

- Added `POST /api/render-resume-html`, backed by the same templates used for PDF export.
- Replaced three React resume layout implementations with a sandboxed backend-rendered preview.
- Preserved summary editing through one template-independent editor with debounced preview refresh.
- Added strict backend profile normalization and validation.
- Removed synthetic role, organization, skill, and title fallbacks from the questionnaire.
- Removed the prefilled skill list that could be ingested as unverified candidate data.
- Enabled Jinja auto-escaping for candidate-controlled resume fields.
- Restricted preview/export template names to the three supported backend templates.
- Added boundary and rendering regression tests.
- Added `FRONTEND_BACKEND_BOUNDARY_AUDIT.md` with ownership decisions and follow-ups.
