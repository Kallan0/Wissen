# Release v1.12.0 — 2026-09-21

## Overview

Corrected the evaluation harness to fail closed on connection and parse failures, diagnosed the invalid baseline run, and implemented the Phase 3 QLoRA training preflight.

## Detailed changes

### `backend/finetuning/evaluate_model.py`

- Request failures and unparseable records now count as hard evaluation errors.
- Added explicit request-failure, failed-record, and validation-error metrics.
- Reran the baseline report: all 30 requests failed because Ollama was unavailable, producing 30 hard failures and a 0% parse rate.

### `backend/finetuning/training_preflight.py`

- Added fail-closed validation for training/holdout schemas and separation.
- Records dataset hashes and package versions.
- Checks required ML dependencies, CUDA/GPU availability, disk capacity, and artifact-output placement.
- Writes a private machine-readable preflight report.

### Tests

- Updated evaluator regression expectations for failed records.
- Added training-preflight coverage.
- Fourteen fine-tuning pipeline tests pass.

## Current blockers

- The baseline must be rerun while Ollama is running.
- The current Python environment lacks `torch`, `transformers`, `datasets`, `accelerate`, `peft`, `trl`, and `bitsandbytes`.
- CUDA is unavailable because PyTorch is not installed; GPU capability must be rechecked in the chosen training environment.
- Disk-space and dataset-integrity checks passed.
