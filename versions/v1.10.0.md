# Release v1.10.0 — 2026-09-21

## Overview

Started the post-dataset implementation plan by completing the Phase 1 automated dataset audit and producing the 30-record manual-review packet required before GPU training.

## Detailed changes

### `backend/finetuning/audit_dataset.py`

- Added read-only auditing of training and holdout JSONL files.
- Verifies JSON/schema validity, identity/contact consistency, static employment/project/education metadata, approved skills, role coverage, dataset hashes, and zero train/holdout overlap.
- Flags unsupported numeric claims, empty/long prose, role imbalance, and repeated normalized summaries/bullets.
- Produces JSON and Markdown reports plus a deterministic 30-record manual-review packet with 10 examples per role.
- Writes all private reports under the ignored `backend/data/finetuning/reports/` directory.

### `backend/tests/test_audit_dataset.py`

- Added tests for clean datasets, report generation, review-packet size, identity drift, train/holdout overlap, and unsupported numeric claims.

### `backend/finetuning/NEXT_STEPS_PLAN.md`

- Recorded Phase 1 automation as complete and training as blocked pending manual approval.

## Audit result

- 120 training and 30 holdout records audited.
- Zero hard errors.
- Zero exact train/holdout overlap.
- One consistent verified candidate identity.
- Two warning categories: eight repeated summaries and 264 repeated bullets.
- A 30-record manual-review packet was generated.
- Twelve fine-tuning and dataset regression tests passed before final documentation updates.

## Rationale

Structural validity alone cannot establish that rewritten prose is factually supported. The new audit automates every deterministic check and leaves only evidence judgment and repetition acceptance to the required manual review.
