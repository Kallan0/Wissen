# v1.18.0 - Midnight Press Theme

Date: 2026-09-24

## Summary

Added a persistent application-wide dark theme that preserves the tactile editorial identity of Wissen Press instead of applying a generic color inversion.

## Changes

- Added a `Night Press` / `Light Press` toggle to the fixed application header.
- Added pre-hydration theme initialization to prevent a light-theme flash.
- Persisted the user selection in `localStorage` under `wissen-theme`.
- Uses the operating-system color preference when no explicit selection exists.
- Converted the paper, ink, manila, terracotta, teal, gold, and press-shadow palette to theme-aware CSS variables.
- Added a warm dark palette with espresso backgrounds, dark dossier cards, parchment text, and brighter editorial accents.
- Updated dotted paper texture, air-mail ribbon, scrollbars, alerts, status panels, and legacy fixed-paper surfaces for dark mode.
- Kept the backend-rendered résumé page white because it represents the print/PDF output rather than application chrome.
- Added appropriate `color-scheme` values so browser form controls follow the selected theme.

## Verification

- `npm.cmd run build`: passed production compilation, linting, and TypeScript validation.
- Production route size: approximately 115 kB first-load JS.
- Theme initialization runs before React hydration and the interactive toggle reconciles against the applied document class.
- Dark palette contrast ratios: body text 15.59:1, card text 14.57:1, muted card text 7.96:1, and primary button text 6.28:1.
