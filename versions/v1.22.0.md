# v1.22.0 - Internship-First Presets and Recommendations

Date: 2026-10-28

## Summary

Repositioned the application's default job targets from senior roles to internships and early-career opportunities.

## Changes

- Replaced the Senior AI/RAG preset with an AI and Full-Stack Engineering Internship.
- Replaced the Senior Python Backend preset with a Python Backend Developer Internship.
- Added a React and UI/UX Design Internship preset.
- Removed experience-year requirements and replaced them with coursework, portfolio, fundamentals, mentorship, and learning expectations.
- Updated target-role placeholders to internship examples.
- Constrained AI role recommendations to Internship, Graduate, Trainee, Junior, or Entry-Level roles.
- Explicitly prohibited Senior, Lead, Staff, Principal, Architect, and management recommendations.
- Reworked deterministic fallback recommendations to internships and removed senior-leadership language.
- Updated cover-letter prompting for early-career applications.

## Verification

- Added regression coverage ensuring all presets remain internship-level and contain no senior or multi-year requirements.
- Added prompt-contract coverage for the early-career recommendation constraint.
